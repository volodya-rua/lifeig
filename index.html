                  Sync with GitHub

                  Everything you add is saved on this device first. Connect a private GitHub repository to keep a copy there and share it between your PC and phone.

                  1. Create a private repository on GitHub, for example lifeig-data.
                  2. Open this token page. It fills in the name and the Contents: Read and write permission for you. Under Repository access choose Only select repositories, pick that repository, then click Generate token.
                  3. Fill in the fields below, paste the token and click Connect and sync. LifeIG checks it straight away and tells you here if anything is missing. Do the same on each device you use.
