                Sync with GitHub

                Everything you add is saved on this device first. Connect a private GitHub repository to keep a copy there and share it between your PC and phone.

                1. Create a private repository on GitHub, for example lifeig-data.
                2. Create a fine-grained token. Under Repository access choose Only select repositories and pick that repository. Under Permissions set Contents to Read and write.
                3. Fill in the fields below. Do the same on each device you use.
